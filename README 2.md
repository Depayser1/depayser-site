# Dépayser Conference Paris 2026

Projeto Next.js reconstruído do zero com as alterações consolidadas da conversa.

## Como abrir

1. Extraia o ZIP.
2. Abra a pasta `depayser-conference-paris-2026` no VS Code.
3. Abra o terminal na raiz da pasta.
4. Execute:

```bash
npm install
npm run dev
```

5. Abra `http://localhost:3000`.

## Importante

O comando `npm run dev` precisa ser executado na mesma pasta em que está o arquivo `package.json`.
